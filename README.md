# Repaso Filosofía 4.º ESO (v2 multijugador)

Juego de repaso tipo Kahoot para clase. La pantalla del profesor (`host.html`, se usa en local, no está en este repo) crea la sala y muestra un QR; el alumnado entra desde su móvil a `play.html`, elige un apodo y responde. La partida se sincroniza por WebRTC (PeerJS); no hay base de datos ni se guarda ningún dato de los participantes.
